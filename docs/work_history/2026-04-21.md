# 작업 이력 - 2026-04-21

## 10:00 - 코드 리뷰 기반 리팩토링 (Critical → High → Medium → Low)

v5.5.0 패키지 분리 이후 코드 리뷰에서 식별된 이슈를
우선순위(Critical → High → Medium → Low)에 따라 순차 개선.
모든 변경은 정상 동작 보존을 전제로 진행.

### Critical (즉시 수정 필요)

#### C1. 캐시 TTL 복합 키 매칭 로직 수정

- 변경된 파일: `ec2menu/core/cache.py`
- 변경 내용: `_get_ttl_for_key`를 최장 prefix 매칭으로 변경
- 이유: `s3_buckets`, `s3_objects`, `cloudwatch_alarms` 등 복합 키가
  동일 prefix 단일 키(`s3`, `cloudwatch`)에 먼저 매칭되어
  잘못된 TTL 적용 가능성 존재
- 추가: 외부 공개 `cache` 싱글톤 바인딩 (기존 `_cache`는 alias 유지)

#### C2. EC2 메뉴 정렬 키 dead code 제거 및 서브메뉴화

- 변경된 파일: `ec2menu/menus/ec2.py`
- 변경 내용:
  - `interactive_select`는 정수 인덱스만 반환 → `sel in ['n','t','s','r']`
    블록은 실행 불가능한 dead code
  - `show_sort_help()` 제거, `choose_sort_key()` 서브메뉴로 전환
  - 정렬 변경 메뉴 항목 추가 (`🔤 정렬 변경 (현재: {key}{↓/↑})`)
- 이유: 기존 키보드 단축키 방식은 기술적으로 작동 불가, 사용자 혼란 유발

#### C3. (오진) S3 URL 내 `shlex.quote` 안전성

- 결론: 재검토 결과 bash가 `s3://bucket/'k w'` 형태를 단일 argv로
  올바르게 연결하므로 실제 보안 이슈 없음
- 수정 없음

### High (중요 개선)

#### H4. S3/SSM 리전별 boto3 클라이언트 사용

- 변경된 파일: `ec2menu/aws/manager.py`, `ec2menu/menus/s3.py`,
  `ec2menu/aws/transfer.py`
- 변경 내용:
  - `_s3_client(region)` 헬퍼 추가
  - S3 list/get/download/presigned/delete 6개 메서드에 `region` 파라미터 추가
  - `download_file_from_s3_to_ec2`에 `instance_region` 파라미터 추가
  - 다중 리전 환경에서 `inst['Region']` 기반으로 SSM 클라이언트 생성
  - S3 예외 핸들링 `except (ClientError, Exception)` → `except Exception`
- 이유: 리전 교차 호출 시 잘못된 엔드포인트/인증 오류 방지

#### H5. MySQL 비밀번호 `ps` 노출 방지

- 변경된 파일: `ec2menu/menus/rds.py`, `ec2menu/core/keychain.py`
- 변경 내용:
  - mysql 커맨드라인 `-p{password}` 제거 → `MYSQL_PWD` 환경변수로 전달
  - `DBEAVER_PATH` 환경변수 오염 제거 → `Config.DBEAVER_PATH` 직접 사용
  - Keychain `security -w` stdin fix 시도했으나 /dev/tty 전용 동작으로
    불가능 → 제약 조건 주석으로 명시
- 이유: `ps aux` 출력에 평문 비밀번호 노출되는 보안 문제
